Lost & Found Portal
A simple MERN Stack web application designed to help students report, search, and manage lost and found items within their college or university.
The portal allows users to create accounts, report lost or found belongings, browse reported items, view item details, and manage their own reports.


Project Overview

The Lost & Found Portal provides a centralized platform where students can report belongings they have lost or found.

Instead of relying on physical notice boards or informal communication, users can use the website to:
Report lost items
Report found items
Browse lost and found items
Search items by name or location
Filter items by category
View complete item details
Manage their submitted reports
Update their profile
Delete their own reports

The project was developed as a college project using the MERN Stack.
